# RS232 to RS485


## 1. Electrical Interfaces

**RS-232** and **RS-485** define electrical signaling. They do not define an application's packet format.

| Property | RS-232 | RS-485 |
| --- | --- | --- |
| Signal measurement | Relative to a common reference | Difference between two bus wires |
| Typical topology | Point-to-point | A terminated bus with multiple nodes |
| Driver connection | Separate transmit and receive signals | Shared pair for half-duplex operation |
| Logic interface | A transceiver converts [logic levels](<../DigitalGeneral.md#logic-levels>) | A transceiver converts differential bus levels |

Do not connect an RS-232 cable directly to a logic-level [UART](<./01-UART.md#1-asynchronous-serial-data>) input.

## 2. Direction and Common Mode

In a two-wire RS-485 system, only one driver should transmit at a time. The protocol controls each driver's enable signal.

Wait until the last stop bit has actually left the UART before disabling its transceiver. An empty transmit buffer only means the bytes have moved onward; the shift register may still be sending the last one.

A differential receiver measures the difference between its wires, but both wires must still stay within its **common-mode range** relative to local ground. Use a suitable reference connection or isolation when differences between the devices' grounds would exceed that range.

## 3. Termination

Place [parallel termination](<../../05-PCB-Layout/03-trace-impedance.md#distributed-loss-and-termination>) at the two ends of a bidirectional bus. Match resistance to cable impedance.

Long branches create additional [reflections](<../../05-PCB-Layout/03-trace-impedance.md#3-reflections>). Keep node branches short relative to the signal transition time.

**Worked example assumptions:** A cable has 120 Ω [characteristic impedance](<../../05-PCB-Layout/03-trace-impedance.md#1-characteristic-impedance>). Two 120 Ω terminators are connected.

1. Their parallel resistance is **60 Ω**.
2. An assumed 2 V differential signal causes about **33.3 mA** through the combined termination.
3. Combined termination dissipation is about **66.7 mW**.

Receiver loading and external bias resistors add further load.

## 4. Idle State and Protection

A **fail-safe receiver** gives a known output when the bus is idle or has certain faults. Check the datasheet: the name does not mean it handles every possible fault.

External bias resistors can hold the idle bus at a known differential voltage. Calculate that voltage with the termination resistors and all receiver loads connected, rather than using the bias divider alone.

Check surge protection, cable shield connections, and isolation requirements at exposed ports.

## 5. Verification

Confirm the vendor's A/B polarity convention with its truth table. Measure both differential voltage and each wire's voltage relative to local ground.
