BJT emitter follower

The emitter follows the base voltage with a base to emitter voltage difference.

The collector connects to the supply. The emitter supplies current to the load.

The voltage gain is slightly below one. The transistor provides current gain, which reduces loading at the input.

The base to emitter voltage changes with current. It is not a fixed voltage drop for every load.

Extract every file into one folder. Open emitter-follower.asc and select Run.
Use View > Step Legend to identify parameter steps.
If no plot appears, open emitter-follower.plt through Plot Settings > Open Plot Settings File.
Default traces: V(in), V(out)

Equal node labels connect. All semiconductor parameters are in the schematic.
Op-amp circuits use UniversalOpamp2, supplied with LTspice. No separate download is needed.
The CIR is the equivalent netlist. The CSV contains original saved samples.
AC data use real and imaginary columns. Time values include the RAW offset.
The website interpolates saved samples. It does not execute LTspice.
